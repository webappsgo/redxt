# Docker Rules (PART 27)

⚠️ **These rules are NON-NEGOTIABLE. Violations are bugs.** ⚠️

## CRITICAL - NEVER DO
- Put Dockerfiles or compose files in the repository root; all Docker definitions belong in `docker/`.
- Use production/dev compose files for automated testing or use project-directory volumes for test/runtime artifacts.
- Bake production debug mode, secrets, runtime-generated configuration, or operator data into images.
- Change the specified entrypoint/CMD contract, omit the rootfs overlay, or put runtime files in `docker/rootfs/`.
- Add optional image variants or workflows unless their files and project requirements actually apply.

## CRITICAL - ALWAYS DO
- Follow PART 27's multi-stage `docker/Dockerfile`, minimal runtime, required utilities, signal handling, entrypoint, and build-time rootfs overlay.
- Use `/config` and `/data` container paths and the prescribed `./volumes` mappings for human deployment compose files.
- Keep production, development, and test compose responsibilities, image tags, service naming, network, ports, restart behavior, and `MODE` settings exactly as specified.
- Build and publish multi-architecture images and apply OCI labels/annotations at build time as required.
- Test images with the required command/health contract; handle no-outbound-network cases exactly as PART 27 specifies.
- Keep AI-driven testing isolated in a project-scoped temp directory and use only the test compose file, preferably through project test scripts.

## TERMINOLOGY
| Term | Meaning |
|------|---------|
| Rootfs overlay | Build-time files copied from `docker/rootfs/` into the image |
| Application container | Docker/Podman/Kubernetes runtime with internal port and path behavior from PART 27 |
| Test compose | `docker/docker-compose.test.yml`, isolated automated-test stack |

## QUICK REFERENCE
- Standard and development images use the required Dockerfiles and tags; do not invent extra variants.
- Runtime config is generated by the binary; compose inputs remain deployment configuration only.
- Read PART 27 for current file names and exact compose/image contracts.
